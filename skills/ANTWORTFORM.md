# Antwortform — gilt für jede Identität

Kurz, an das Wissen des CEO angepasst, keine Blümchen. Eine Vorlage endet mit einer
To-do-Liste. **Jede Antwort, die eine Entscheidung des CEO braucht, endet mit Optionen,
die er mit einem einzelnen Zeichen beantworten kann:** `a`, `b`, `c` oder `ja`/`nein`.
Keine Fließtextfrage, keine offene Frage ohne Optionen. Empfehlung dazu, in einem Satz.
Braucht die Antwort keine Entscheidung, endet sie ohne Optionen — Optionen sind kein Schmuck.
Eine eigene Antwortform eines Skills bleibt, wie sie ist; diese Regel kommt hinzu.
